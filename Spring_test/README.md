# Web сервис для расчета чисел Фибоначчи

Сервис позволяет через HTTP запрос получить значение числа
Фибоначчи.

Сервис включает в себя кэширование уже совершенных вычислений
и не производит повторных вычислений для известных чисел.

## Требования для запуска

- Java 17
- Docker (для запуска БД Postgres и тестов)

Перед запуском приложения у вас должна быть запущена БД.
Вы можете запустить БД Postgres версии 16.x и выше локально
или использовать скрипты для запуска контейнера в Docker.

Для Linux/Mac/WSL2 используйте

```shell
./run-postgres.sh
```

Для Windows:

```shell
./run-postgres.bat
```

## Запуск приложения

### Через среду разработки Intellij IDEA и ее аналогов

Найдите класс `TestFibonacciApplication` и выполните запуск через кнопку Run.

### Через CLI

Проект содержит Maven Wrapper и вы можете использовать его для запуска:

```shell
./mvnw spring-boot:run
```

## Использование приложения

Выполните HTTP запрос `http://localhost:8080/fibonacci/{index}`
с указанием индекса числа Фибоначчи и получите расчет. Пример:

http://localhost:8080/fibonacci/15

```json
{
  "index": 15,
  "value": 610
}
```

## Баги

Приложение содержит один известный баг.

При запросе значения числа Фибоначчи начиная с индекса 47 первый запрос
на пустой БД возвращает верное значение, повторные запросы возвращает
ошибочное значение.

Как воспроизвести:

1. Выполните запрос GET http://localhost:8080/fibonacci/47

```json
{
  "index": 47,
  "value": 2971215073
}
```

2. Повторите запрос GET http://localhost:8080/fibonacci/47

```json
{
  "index": 47,
  "value": -1323752223
}
```
