Запуск контейнера с Redis
docker run --rm --name skill-redis -p 127.0.0.1:6379:6379/tcp -d redis

Программа эмулирует работу сайта:
- в консоль выводится номер пользователя, которого нужно отобразить на главной странице;
- в одном из десяти случаев случайный пользователь оплачивает услугу,
  в консоль выводится его номер;
- программа ждёт одну секунду, и цикл начинается заново.
